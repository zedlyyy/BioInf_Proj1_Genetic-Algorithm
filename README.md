# BioInf_Proj1_Genetic-Algorithm
Project made by **Pedro Galego** nº72298 for the Bio Informatics Class.
# Description
In this project we were asked to make a Genetic Algorithm with the objective of finding the optimal MSA from a set of individuals using a score-based selection with operators such as Mutations and Crossovers to apply diversity to the indivisuals.
## Instructions
- Just run the `project1.py` and the algorithm will do it's thing !
- Parameters such as `POP_SIZE` and `GENERATION_SIZE` can be adjusted inside the `project1.py` file !
